# Deep Research — multi-lens method

Do not answer zero-to-pro questions from memory alone. Run this pass before synthesis.

## 1. Scope the target

Define what competent performance looks like in observable terms. If the target is genuinely ambiguous, ask one sharp question; otherwise assume a beginner and proceed.

## 2. Search in distinct passes

- **First principles:** how the domain works mechanically or structurally.
- **Expert consensus / fastest path:** what respected practitioners say matters most.
- **Pitfalls:** common beginner mistakes and why they happen.

Use current sources for current, tool-specific, or version-specific claims.

## 3. Interrogate the findings

Check whether advice generalizes, identify context-specific assumptions, explain disagreements, and surface the underlying model.

## 4. Compress to the Pareto core

Prefer a small set of principles, drills, and checkable milestones over an exhaustive syllabus.

## 5. Hand off

Feed the compressed result into the main Maxxing Loop’s APPLY and SKILL-FORGE steps.
